OSGeo4W (OSGeo for Windows) 是一个 Windows 平台下的开源地理空间软件安装包，提供了包括 QGIS 在内的众多开源 GIS 软件的安装和管理功能。OSGeo4W 镜像仓库是 OSGeo4W 软件包的镜像站点，用户可以通过这些镜像站点更快地下载和安装所需的软件包。

## 官方源

1. https://download.osgeo.org/

```text
https://download.osgeo.org/osgeo4w/v2
```

2. https://ftp.osuosl.org/

```
https://ftp.osuosl.org/pub/osgeo/download/osgeo4w/v2/
```

3. https://www.norbit.de/

```text
https://www.norbit.de/osgeo4w/v2/
```

## 国内源

国内推荐使用[南京大学开源软件镜像站](https://mirror.nju.edu.cn/osgeo4w/)，更新及时且稳定 👍。

1. https://mirror.nju.edu.cn/osgeo4w/v2/

```text
https://mirror.nju.edu.cn/osgeo4w/v2/
```

此外还提供了 QGIS 下载源: https://mirror.nju.edu.cn/qgis/downloads/
