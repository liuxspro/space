## 添加 MDX 组件

`mdx-components.tsx`中`getMDXComponents`返回了mdx笔记中默认可使用的组件。

有些组件默认没有加入，比如`Accordion`，需要在mdx文档中引入才能使用。

```typescript
import { Accordion, Accordions } from "fumadocs-ui/components/accordion";
```

可以将组件添加到`mdx-components.tsx`中，默认就可以使用了。

```typescript
import { Accordion, Accordions } from "fumadocs-ui/components/accordion";

export function getMDXComponents(components?: MDXComponents): MDXComponents {
  return {
    ...defaultMdxComponents,
    img: (props) => <ImageZoom {...(props as any)} />,
    ...components,
    Accordion,
    Accordions,
  };
}
```

另外，也可以添加自定义的组件。

## 更改翻译

默认语言是英文，如目录（On this page），搜索（Search）等。可以添加对应的中文翻译。

在`src/app/layout.tsx`中引入翻译文件，并传递给`RootProvider`。

```typescript
import type { Translations } from 'fumadocs-ui/i18n';

const cnTranslations: Partial<Translations> = {
  search: "搜索",
  toc: "目录",
  searchNoResult: "无搜索结果",
};
// 添加到RootProvider中
<RootProvider
  i18n={{
    locale: "cn",
    translations: { cn: cnTranslations }["cn"],
  }}
>
```

## 如何修改样式

> 比如引用块的字体是斜体，不习惯。

暂时想到的方法是在`src/app/global.css`中覆盖样式。

```css
/* 引用块取消斜体和括号 */
blockquote {
  @apply not-italic bg-gray-200 dark:bg-gray-800 py-2;
  quotes: none;
}

blockquote p {
  @apply my-0;
}
```

## 修改脚注标题

脚注标题默认是"Footnotes"，可以通过修改`source.config.ts`中的`remarkRehypeOptions`来更改标题文字。

这是remark-rehype的配置项，See: https://github.com/remarkjs/remark-rehype?tab=readme-ov-file#footnotes

```typescript
export default defineConfig({
  mdxOptions: {
    // MDX options
    remarkRehypeOptions: {
      footnoteLabel: "参考", // 将脚注文本 Footnotes 翻译成中文
    },
  },
});
```
