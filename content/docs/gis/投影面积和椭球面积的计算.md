## ArcGIS

Arcmap 中计算几何默认是算的是投影面积（根据坐标系来），在字段计算器中，可分别计算椭球面积和投影面积（Python 模式）。Arcgis Pro 中面积（测地线）就是椭球面积。

```
# 投影面积
!Shape.Area!

# 椭球面积
!Shape.geodesicArea!
```

## QGIS

识别要素中的**面积（椭球体）**、**面积（笛卡尔坐标）** 分别代表了**椭球面积**和**投影面积**。在字段计算器中，可使用 `$area` 计算椭球面积，使用 `area(@geometry)` 计算投影面积。
